# Basic Calculator

Ultra-simple calculator with 4 operations: add, subtract, multiply, divide.

## Usage

```python
from calculator_basic_refactored import add, subtract, multiply, divide

print(add(5, 3))        # 8
print(subtract(10, 3))  # 7
print(multiply(4, 3))   # 12
print(divide(10, 2))    # 5.0
```
